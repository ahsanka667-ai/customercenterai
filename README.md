# CustomerCenter AI

AI order confirmation for Facebook-first and website sellers.

**Read the plan: [PLAN.md](./PLAN.md)**

The short version:

- Facebook is **not** a phone channel. Messenger is intake + in-window chat; the confirmation call runs over telephony.
- Build the voice confirmation engine once, then add website/CSV, Messenger, comments, and Lead Ads as adapters.
- Start Meta Business Verification and App Review in week 1 — approval is the long pole.
- Wedge: COD order confirmation in Bangla within 5 minutes of the order, with address repair and a structured outcome.

Status: planning / pre-MVP.
